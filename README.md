# Gleivia Silva Estética

Site editorial e responsivo para Gleivia Silva Estética, no Porto.

## Incluído

- Direção visual premium inspirada nas referências enviadas.
- Hero editorial com CTA para agendamento.
- Serviços principais e acesso ao catálogo/agenda no Fresha.
- Apresentação da profissional.
- Comparador interativo de imagens.
- Galeria e depoimentos.
- Localização e horários.
- Experiência mobile com CTA fixo para agendamento.

## Agendamento

Os CTAs utilizam o fluxo oficial de booking do Fresha para manter disponibilidade e reservas centralizadas.

## Observação

O comparador utiliza duas imagens do portfólio apenas para demonstrar a interação. Para publicação final, substitua por pares reais de antes/depois autorizados pela profissional.
